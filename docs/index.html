What the app does

The app shows month and day views, lets users create and edit events, and syncs supported calendars and tasks after the user signs in and grants permission.

Why Google access is requested

Google OAuth is used to connect the user's own Google account so the app can:

  • read the list of Google calendars available in the signed-in account,
  • read and display calendar events and Google Tasks,
  • create, update, and delete events or tasks when the user chooses to do so.

How access works

Access is granted only after the user explicitly signs in with Google and consents to the requested permissions. The app does not access calendar data for users who have not connected their Google account.

Data handling summary

Calendar and task data is used only to provide in-app scheduling and sync features. For more details about collection, storage, and deletion, see the privacy policy.
